# 決定事項

[plan.md](plan.md) の質問への回答と、それを受けて確定した事項を記録します。「既定」は、異論がなければそのまま確定とする項目です。

| 日付 | 項目 | 状態 | 内容 | 根拠 |
|---|---|---|---|---|
| 2026-11-06 | 公開先 | 決定 | Vercel（Hobby、個人アカウント） | 使うのは本人だけで、支払い・広告・販売のない個人のツール。商用と判断された場合の影響も小さい（plan.md の質問 2） |
| 2026-11-06 | アクセス制限 | 既定 | 付けない | 配る HTML に秘密はなく、PDF はサーバーに届かない |
| 2026-11-06 | 配信のしかた | 既定 | ホスト側でビルドせず、コミットした `dist/` をそのまま配る | 配信物を、レビュー済みのコミットと同じものにする |
| 2026-11-06 | アカウントの守り | 既定 | GitHub と Vercel の両方に 2 段階認証を設定する（利用者の作業） | 配信物を書き換えられるのは、この 2 つのアカウントだけ |
| 2026-11-06 | `'wasm-unsafe-eval'` | 決定 | 許可する | スキャン PDF の CCITT・JBIG2・JPEG 2000 の復号に要る（security.md） |
| 2026-11-06 | 対象ブラウザ | 決定 | Windows の Chrome（最優先）。CI で Windows の Edge と macOS の Chrome も確かめる | 利用者の社用 PC は Windows、ブラウザは Chrome |
| 2026-11-06 | CI | 決定 | GitHub Actions で、Linux（ビルド、単体、E2E）と Windows・macOS（E2E）を回す | 開発環境が Linux だけのため。公開リポジトリなので無料 |
| 2026-11-06 | 同梱する標準フォント | 決定（報告事項） | Symbol と ZapfDingbats 用の Foxit フォントだけ。Liberation Sans は入れない | Liberation Sans は GPLv2（フォント例外つき）で、許容的なライセンスの方針に合わない。ほかの標準フォントは PC のフォントで描く（design.md） |
| 2026-11-06 | UI の文言 | 決定 | 「アップロード」ではなく「開く」 | このツールは何も送信しないため |
| 2026-11-06 | 自動の候補を探す時期 | 決定（報告事項） | PDF を開いて文字の情報を読み終えたら、有効な種類（日付・年号以外）で自動で 1 回探す。結果は開いた直後の状態として扱い、元に戻す対象にしない | 依頼の 3-2 は「正規表現による候補の検出」。開くたびに押す手間をなくし、押し忘れによる見落としを防ぐ。候補は未確認のままなので、塗るかどうかは人が決める |
| 2026-11-06 | 日付・年号の検出 | 決定 | 既定では無効。チェックを入れて「この設定で探す」で使う | 依頼のとおり。学歴・職歴の年月まで候補になり、確認の手間が増えるため |
| 2026-11-06 | 文字の位置の見積もり | 決定（報告事項） | 全角を 1 字分として、半角の幅を断片の幅から求める。等幅の半角は正確に割り付け、それ以外は半角の字数に応じた余裕を候補の矩形に足す | 全角と半角が混ざる行（「ご連絡は taro@… か、０９０…」など）で、固定の比による近似では、電話番号の候補の枠が数字の端を覆わなかった（E2E で検出）。漏れに直結するため（design.md） |
| 2026-11-06 | ページの出力からの除外 | 決定 | 各ページの上の「このページを書き出す」のチェックで切り替える。元に戻せる操作にする | 依頼の 3-2 のとおり。外したページの未確認の候補は、書き出し前の確認の対象にしない |
| 2026-11-06 | 拡大・縮小 | 決定 | 25〜400% の段階と「幅に合わせる」。範囲の座標は倍率に依存しない | 依頼の 3-2 のとおり |
